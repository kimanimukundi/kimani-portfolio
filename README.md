# Kimani Mukundi — Portfolio

My personal portfolio website, built with Next.js, TypeScript, and CSS Modules.

## Tech stack

- Next.js 16
- TypeScript
- CSS Modules
- Deployed on Vercel

## Running locally

\```bash
npm install
npm run dev
\```

Open [http://localhost:3000](http://localhost:3000)
